## 2. P2-9 rev 1 — the user asked for a no-band-aid review; the per-face design was replaced

- **My error, found when the user asked to be careful about angled faces.** I had claimed that reading along a grid
  axis "stretches" the profile on a sloped wall and spoils T_s, h_f and the criterion.
  - It does not. Along ANY straight line into the rock the profile is exponential with ℓ/μ. The two-cell
    reconstruction recovers it exactly, the flake along the line is h_n/μ, and receding the line by that moves the
    surface by h_n.
  - Rescaling the spacing AND the recession is a no-op; rescaling one of them is the 1/μ² trap (2× at 45°), already
    recorded 2026-09-21 (`2026-09-21b.md`:187–193).
  - Only lengths that are physical NORMAL distances (`flake_h_max`, the scan window) convert by ÷ μ.
- **What really breaks the per-face design:**
  1. double recession (a stair cell's top and riser both recede);
  2. shallow-line reads from risers;
  3. a tie-break between faces.
- **The fix is one line per surface cell** along the exposed face most aligned with the normal. For a plane, the
  exposed cells are exactly one per line along the dominant axis (proof: surface cells satisfy
  c − n_max ≤ n·p < c), so nothing is counted twice and the floor is the μ = 1 case.
- **Kept from the first review:**
  - a per-cell solid fraction instead of the direction-free bank;
  - no x-hold: it decided 0.05 % / 0.03 % of floor firings on P2-8 K0 / P47, and the face heat balance replaces it;
  - one removal function any mechanism can feed (vaporisation for MMW);
  - risers use the cell's T_s with their area weight.
- **Gates:** floor key 0 vs 1 within 0.1 % (exactness lost with the hold); tilted planes 20/35/45/60°, the diagonal
  and a rotated azimuth within 2 %. Predicted residual: cross-line averaging, u²/6 (0.6 % at 30°, 1.2 % at 45° at
  1 mm).

## 4. Review of the rev 1 code (advisor), and two of my own errors

Seven items, all verified against the code:
1. Fallback flake = one cell.
2. Hand-written Neumann ghost fill.
3. Three-plus copies of ν and the confining offset.
4. `through` removes only part of the slab.
5. The `Makefile` `.d` is only rebuilt when the `.cc` changes, so `Grimsel.H` and `FaceRemoval.H` are invisible to
   make.
6. Overlap is operator splitting (fine; measure it).
7. Misaligned cells are counted as sheets.

My errors:
- **Area fix, wrong on curves.** "One area per cell, dx²/μ" over-counts curves (+4.1 % sphere, +4.6 % bore). The fix
  is P2-8's per-face rule with a normal from the solid fraction smoothed over 5×5×5 (σ 1). Error: planes ≤ 1.8 %,
  spheres ≤ 1.2 %, bore −2.8 %, cube −5 %.
- **"Line recession over-removes on curves", wrong as a rate claim.** The per-firing volume excess cancels in steady
  state, because heat in = flake enthalpy out. So the rate error is the area error alone. This also removed my stated
  reason for a 4 % tilt bar. The predictions are now ≤ 1.6 %, and the 4 % bar (user's choice) leaves room for the
  ~1.7-point fixture spread.
- **σ = 1 needs 3 ghost layers,** not 2 as I told the user: ±2 for the smoothing plus ±1 for the gradient.

User decisions: σ = 1 with a 4 % bar; `Makefile` fix approved.
